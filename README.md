# Leafscan

LeafScan AI is a project I built to see how accurately a neural network could identify plant diseases from a single photo of a leaf.

The app lets you upload an image and returns the top 3 most likely diagnoses with confidence scores. The model was trained on over 70,000 images covering 38 disease classes across 14 different plant types.

I wanted to learn more about computer vision, model deployment, and how machine learning systems can be turned into tools that real people can use.
